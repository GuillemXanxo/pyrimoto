## 2. Quines dades personals podem recollir?

El titular podrà tractar les dades personals que l'usuari faciliti voluntàriament quan es posi en contacte per consultar informació sobre les rutes o el servei d'acompanyament.

Aquestes dades poden incloure:

- Nom i cognoms.
- Adreça electrònica.
- Número de telèfon, si l'usuari el facilita.
- Contingut del missatge o de la consulta.
- Informació necessària per concretar una possible sortida amb moto, com ara la data, la ruta o les preferències comunicades voluntàriament.

També es poden tractar dades tècniques bàsiques de navegació, com ara l'adreça IP, les dades de connexió o les dades obtingudes mitjançant galetes, quan sigui necessari i d'acord amb la configuració tècnica del lloc web i la normativa aplicable.

No es demanaran dades personals que no siguin necessàries per a les finalitats descrites.

## 3. Finalitats i bases jurídiques del tractament

Les dades personals es tractaran amb les finalitats següents:

**a) Atendre consultes i sol·licituds d'informació.**

Utilitzarem les dades de contacte i el contingut del missatge per respondre les preguntes relacionades amb les rutes i el servei.

- Base jurídica: aplicació de mesures precontractuals sol·licitades per l'interessat quan la consulta estigui relacionada amb la possible contractació del servei; en altres consultes, la base jurídica que correspongui segons el seu contingut.

**b) Preparar i prestar el servei d'acompanyament.**

Quan l'usuari manifesti interès a contractar el servei, les dades necessàries es podran utilitzar per concretar-ne les condicions, coordinar la sortida i mantenir les comunicacions relacionades amb la prestació.

- Base jurídica: aplicació de mesures precontractuals i execució del contracte, segons correspongui.

**c) Complir obligacions legals.**

Les dades que siguin necessàries es podran conservar o comunicar per complir obligacions fiscals, comptables o altres obligacions legals aplicables.

- Base jurídica: compliment d'una obligació legal.

**d) Garantir el funcionament i la seguretat del lloc web.**

Les dades tècniques imprescindibles es podran tractar per mantenir la seguretat, detectar errors i prevenir usos indeguts.

- Base jurídica: interès legítim, quan sigui aplicable i després de valorar els drets i interessos de les persones afectades, o una altra base jurídica que correspongui.

No s'utilitzaran les dades per enviar publicitat o butlletins comercials sense disposar de la base jurídica necessària.

## 4. Destinataris de les dades

Les dades personals no es vendran ni es cediran a tercers amb finalitats comercials.

Tanmateix, hi podran tenir accés els proveïdors que siguin necessaris per al funcionament del lloc web o per a la gestió de les comunicacions, com ara el proveïdor d'allotjament web o el servei de correu electrònic, sempre que correspongui i amb les garanties exigides per la normativa.

També es podran comunicar dades a administracions públiques, jutjats, tribunals o altres autoritats quan hi hagi una obligació legal.

Aquest lloc web no gestiona reserves d'allotjaments, restaurants o altres activitats, ni tramita pagaments anticipats. Per tant, no es recullen dades de targetes bancàries amb aquestes finalitats.

## 5. Transferències internacionals de dades

El titular no preveu transferir dades personals fora de l'Espai Econòmic Europeu, llevat que algun dels proveïdors utilitzats impliqui aquest tipus de transferència.

Si es produeix una transferència internacional, s'haurà de dur a terme d'acord amb els requisits del RGPD i s'informarà de les garanties aplicables quan correspongui.

## 6. Terminis de conservació

Les dades es conservaran només durant el temps necessari per complir la finalitat per a la qual s'han recollit i per atendre les responsabilitats legals que se'n puguin derivar.

Com a criteri general:

- **Consultes sense contractació:** durant el temps necessari per respondre-les i fer-ne el seguiment raonable.
- **Comunicacions relacionades amb un servei contractat:** durant la relació contractual i, posteriorment, durant els terminis legals de prescripció que siguin aplicables.
- **Documentació fiscal i comptable:** durant els terminis de conservació exigits per la normativa corresponent.
- **Registres tècnics i de seguretat:** durant el període justificat per les necessitats de seguretat i funcionament del lloc web.

Quan les dades deixin de ser necessàries, s'eliminaran o es bloquejaran quan legalment correspongui.

## 7. Drets de les persones usuàries

Les persones interessades poden exercir, quan siguin aplicables, els drets següents:

- **Accés:** saber si es tracten les seves dades i obtenir-ne una còpia.
- **Rectificació:** corregir dades inexactes o incompletes.
- **Supressió:** sol·licitar que s'eliminin les dades quan es compleixin els requisits legals.
- **Oposició:** oposar-se a determinats tractaments.
- **Limitació:** demanar que se'n restringeixi el tractament en els supòsits previstos legalment.
- **Portabilitat:** rebre les dades en un format estructurat i d'ús habitual quan es compleixin els requisits legals.
- **Retirada del consentiment:** quan el tractament es basi en el consentiment, retirar-lo en qualsevol moment, sense afectar la licitud del tractament anterior a la retirada.

Per exercir aquests drets, es pot enviar una sol·licitud a l'adreça electrònica indicada a l'apartat 1, especificant el dret que es vol exercir. Es podrà demanar informació addicional raonablement necessària per verificar la identitat de la persona sol·licitant.

També es pot presentar una reclamació davant l'Agència Espanyola de Protecció de Dades (AEPD) a través de [www.aepd.es](http://www.aepd.es) si es considera que el tractament de les dades no s'ajusta a la normativa.

## 8. Caràcter obligatori de les dades

Les dades identificades com a necessàries per respondre una consulta o gestionar el servei s'hauran de facilitar perquè es pugui atendre la sol·licitud.

Si no es faciliten, és possible que no es pugui respondre la consulta o concretar el servei. Les dades que no siguin necessàries no s'hauran de facilitar.

## 9. Galetes i tecnologies similars

Aquest lloc web utilitzarà únicament les galetes i tecnologies que corresponguin a la seva configuració real.

Les galetes tècniques estrictament necessàries per prestar un servei sol·licitat per l'usuari poden quedar exemptes del consentiment previ en els termes legalment establerts. Les galetes d'anàlisi, publicitat o altres finalitats no exemptes només s'activaran quan es disposi del consentiment necessari.

Si el lloc web utilitza galetes no necessàries, s'haurà de publicar una política de galetes que identifiqui les galetes utilitzades, les seves finalitats, els seus responsables i els terminis de conservació, i s'haurà d'oferir un mecanisme adequat per gestionar el consentiment.

## 10. Seguretat de les dades

El titular adoptarà les mesures tècniques i organitzatives raonables i adequades per protegir les dades personals contra l'accés no autoritzat, la pèrdua, l'alteració o la divulgació indeguda.

No obstant això, cap sistema de transmissió o emmagatzematge electrònic pot garantir una seguretat absoluta.

## 11. Dades de menors d'edat

Aquest lloc web no està destinat específicament a menors d'edat. No es recolliran deliberadament dades de menors sense la base jurídica i, quan sigui necessari, l'autorització corresponent.

Si el titular detecta que ha rebut dades que no s'haurien d'haver recollit, adoptarà les mesures que corresponguin d'acord amb la normativa aplicable.

## 12. Modificacions de la política de privacitat

El titular es reserva el dret d'actualitzar aquesta política per adaptar-la a canvis normatius, tècnics o en el funcionament del servei.

La versió vigent estarà disponible permanentment en aquest lloc web i indicarà la data de la darrera actualització.
